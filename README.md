## About the Project

This project was completed as part of **D486 – Secure Systems Management**, a WGU course focused on applying NIST-based security frameworks, assessing organizational risks, and developing remediation policies to strengthen system security and compliance posture.

The scenario centers on **Fielder Medical Center (FMC)**, a healthcare organization with several gaps in its security controls, policies, and compliance readiness. Acting as a cybersecurity consultant, I was tasked with identifying and addressing these weaknesses using NIST SP 800-53 Rev. 5 and PCI DSS standards.

The deliverables included:

* A full **security assessment** identifying deficiencies in FMC’s existing framework
* A **risk justification and prioritization** analysis based on NIST control families
* A detailed **remediation plan** mapping actions to specific control identifiers
* A **PCI DSS-compliant security policy** for firewall, antivirus, and authentication configuration

This project reinforced my understanding of compliance-driven security management, documentation standards, and policy enforcement aligned to federal and industry regulations.

## Scenario

Fielder Medical Center (FMC) is a healthcare provider operating multiple information systems that handle **personally identifiable information (PII)** and medical documentation.
An independent **Security Assessment Report (SAR)** revealed significant weaknesses in FMC’s controls, policies, and infrastructure, including:

* Outdated **System Security Plan (SSP)** and lack of current risk assessment
* Missing **least-privilege enforcement** (AC-6) and **multifactor authentication (MFA)**
* Poor **endpoint protection** and inconsistent antivirus coverage
* No **continuous monitoring (CA-7)** or **Plans of Action and Milestones (CA-5)**
* Incomplete preparation for **PCI DSS compliance**

As part of this task, I identified the highest-risk control areas, justified remediation priorities, and authored a new **PCI DSS-compliant policy** for implementation across FMC systems.

## Key Deliverables

### 1. Security Gap Assessment

Identified and summarized weaknesses in FMC’s current security and compliance framework across NIST control families.

### 2. Risk Identification and Justification

Prioritized high-impact controls including:

* **AC-6 (Least Privilege)**
* **CA-5 (Plans of Action and Milestones)**
* **CA-7 (Continuous Monitoring)**
* **RA-3 (Risk Assessment)**
* **RA-7 (Risk Response)**

### 3. Risk Remediation Plan

Outlined corrective actions, assigned responsibilities, and proposed monitoring mechanisms to maintain accountability.

### 4. PCI DSS-Compliant Policy

Developed formal policies covering:

* Firewall configuration and vendor default removal
* Antivirus and endpoint protection
* Multifactor authentication for secure portal logins

Each policy includes defined **roles and responsibilities** for IT Security Administrators, System Administrators, and the CISO.
